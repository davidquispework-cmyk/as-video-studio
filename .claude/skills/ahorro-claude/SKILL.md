# Gastar poco del plan Pro

## Lo que hace Claude
- Leer solo lo necesario (buscar con grep y leer trozos, no ficheros enteros).
- No repetir pruebas pesadas: una comprobación final, no diez.
- Respuestas cortas; nada de repetir lo que ya está dicho.
- No lanzar subagentes salvo que David lo pida.
- Hacer el trabajo en pocos pasos grandes, no muchos pequeños.
- Guardar en el repositorio (skills, notas) lo decidido, para no volver a explicarlo.

## Lo que hace David (decírselo cuando haga falta)
1. Todo en UN mensaje: lo que quiere + datos + archivos/enlaces de Drive.
2. Una tarea por conversación; abrir una nueva para otro tema (las largas cuestan más
   porque se relee todo).
3. Empezar con el límite de la sesión recién reiniciado (se reinicia cada pocas horas;
   el semanal, el lunes).
4. Adjuntar el archivo concreto, no «mira todo el proyecto».
5. Para cosas simples (un texto, una duda) usar el chat normal, no una sesión de código.
6. Decir «sin pruebas pesadas» cuando no haga falta probar a fondo.
